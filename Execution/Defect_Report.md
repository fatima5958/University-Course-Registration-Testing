| Defect Title | System allows duplicate course registration |
| Requirement ID | R05 |
| Test Case ID | TC06 |
| Environment | Windows, Google Chrome |
| Steps to Reproduce | 1. Open registration.html. 2. Enter name and valid email. 3. Select Software Engineering. 4. Click Register. 5. Click Register again using the same details. |

| Priority | High |
| Status | Open |
