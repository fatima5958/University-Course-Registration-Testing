# Software Test Plan

Project: University Course Registration System  
Course: CCS366 – Software Testing and Automation  
Task: Test Plan and Test Case Design  
Prepared by: Mateen Fatima  
Date: 11 November 2026

## 1. Objective and Scope

The objective of this testing is to check whether the University Course Registration System works correctly.

The testing will cover:

- Required name validation.
- Email address validation.
- Course selection.
- Course capacity limit (30 students).
- Duplicate registration prevention.
- Registration confirmation.

## 2. Testing Approach

- Positive Testing: Check registration with valid information.
- Negative Testing: Check invalid or missing information.
- Boundary Testing: Check course capacity, especially when 30 students are registered.
- Retesting: Test again after fixing a defect.
- Regression Testing: Check that existing features still work after a fix.

## 3. Test Environment

- Device: Computer/Laptop
- Operating System: Windows
- Browser: Google Chrome
- Application: University Course Registration System
- Tools: MS Excel, MS Word

## 4. Testing Risks

- Application may crash or stop responding during testing.
- Incorrect test data may produce unreliable test results.
